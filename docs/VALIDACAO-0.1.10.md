# Validação do ColorCraft 0.1.10

Formatação, testes da área de trabalho e Clippy executados após corrigir a cobertura das traduções. Os testes de localização cobrem os rótulos de detalhes, contagens, seleção e plurais do resumo de relações técnicas.

A auditoria mantém conteúdo escrito pelo usuário — nomes de paletas, cores, pastas, tags, papéis, modos e notas — no idioma original. Só textos da interface são traduzidos.

Distribuição Windows em pasta e ZIP separados. As distribuições anteriores e a instância já aberta pelo usuário foram preservadas.
