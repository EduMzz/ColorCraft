# Proveniência dos ativos

`colorcraft.png`: cópia byte a byte de `Logo ColorCraft - menor.png`, fornecida por Eduardo em 17/10/2026 para o aplicativo ColorCraft. Ícone original de pavão amarelo, preto e branco. O arquivo de maior resolução permanece na origem e não é necessário ao executável.

`colorcraft-128.png` e `colorcraft.ico`: redimensionamentos técnicos do mesmo arquivo para janela/ícone Windows. Sem alteração do desenho.

`palette-file.png` e `palette-file-small.png`: cópias byte a byte, respectivamente, dos arquivos “ColorCraft File Icon.png” e “ColorCraft File Icon menor.png”, fornecidos por Eduardo em 18/10/2026. `palette-file.ico` é uma conversão para o ícone multi-resolução do Windows, com transparência preservada e sem alteração do desenho. Usados na associação de `.colorcraft` e `.colorcraft-palette`.

O usuário autorizou o uso no aplicativo ao solicitar a implementação com esse ícone. Não foi declarada uma licença geral da ilustração para reutilização independente. As licenças MIT/Apache do código não abrangem automaticamente essas imagens.

Nenhum logo ArtCraft, VectorCraft ou ativo de concorrente foi incorporado. Ícones geométricos de navegação são desenhos vetoriais próprios no código. As fontes incorporadas são as padrões do egui; seus avisos acompanham as dependências no pacote.

Na versão 0.1.1, os ícones vetoriais da interface reproduzem os paths do arquivo `icons.mjs` do Colorator deste workspace, conforme escolha expressa de Eduardo. São interpretados e desenhados em Rust, com complementos geométricos para informações e controles da janela; não usam glifos Unicode como substitutos.
